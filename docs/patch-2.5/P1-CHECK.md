Запускать вручную через `runtime/preview/e9365303e144b8f0965388bf9bb3a12dcbea8d7b8c7a63765dc903ee636850f0/Start Katran Preview.cmd`. У превью отдельная подпапка данных; не направлять её на обычные данные Катрана.

## Перед запуском

В Проводнике создай отдельные временные папки `P1-source` и `P1-destination`. В `P1-source` нарисуй в Paint PNG-файлы `move.png`, `pinned.png` и `conflict.png`, а также создай `note.md`. В `P1-destination` создай свой `conflict.png` с другим рисунком. Для проверки живых изменений оставь источник открытым и добавляй/меняй только тестовые файлы; личные файлы не используй.

## Проверки

1. **Поиск папки.** Открой выбор Folder через Everything, найди `P1-source` и открой её. Добавь папку в избранное, перейди в другую категорию и вернись к выбору; проверь повторный доступ через историю и избранное.
2. **Содержимое Folder.** Убедись, что видны файлы выбранной папки. Создай, измени и удали один временный файл во внешнем приложении; проверь обновление Folder без перезапуска.
3. **Предпросмотр.** В Folder открой PNG и Markdown через Space, закрой Escape. Убедись, что это просмотр, а файлы на месте.
4. **Возврат в Катран.** В `P1-source` выбери три PNG и используй `Ctrl+Shift+C`. Проверь, что каждый объект появился в Катране один раз. Другие типы файлов тоже можно попробовать, но сейчас не все возвращённые не-изображения получают классификацию.
5. **Перемещение с закреплённым объектом.** В одной категории закрепи `pinned.png`, выбери его вместе с `move.png` и `conflict.png`, затем переключи Folder на `P1-destination` и выполни `Ctrl+X → Tab → Ctrl+V`. Незакреплённый успешный элемент должен переместиться; закреплённый должен остаться в потоке и дать копию в Folder. Убедись, что уже существующий `conflict.png` не перезаписался молча, и запиши точный результат конфликта.
7. **Обычное копирование из Folder.** Обычные Ctrl+C и drag из Folder сейчас имеют известную ошибку передачи (metadata/ref digest); не засчитывай их как пройденные и не делай вывод о подавлении повторного захвата. После исправления отдельно проверь успешное копирование и отсутствие нового объекта в потоке.

## Не проверять в P1

- Удаление файлов из Folder и отрицательный сценарий Ctrl+X из Folder пока не поддерживаются.
- Вставка в Folder из внешнего системного буфера обмена пока не поддерживается.
- Редактирование имён/свойств и тегов через GUI ещё не готово.
- Не удаляй оригиналы из Screenshots и Downloads: исправление корзины ещё ожидается, поведение Screenshots может быть необратимым.

Запиши фактический результат и скриншот/шаги только для наблюдённых проблем. Не считай известные ограничения проверенными функциями.
