## 📁 Folder вместо All

Folder показывает файлы одной выбранной папки. Подпапки не отображаются, не открываются и не участвуют в массовых операциях. Нет файлового дерева и рекурсивного представления. Саму рабочую папку через выбор её содержимого удалить нельзя.

- Tab открывает Folder из номерной категории и возвращает к последней номерной категории из Folder.
- Внутри Folder доступны существующие инструменты Катрана: одиночный и множественный выбор, сортировка, быстрый просмотр и палитра команд.
- Верхняя строка поиска в Folder ищет среди файлов текущей директории. Это отдельная задача от поиска папки через Everything.
- Ctrl+Enter показывает существующий файл в Проводнике; Ctrl+Shift+Enter открывает выбор приложения. Обычные команды открытия сохраняются.
- Содержимое живое: внешнее добавление, удаление или перемещение файла отражается в Folder. Катран не держит исчезнувший файл как существующий.
- Выбранная папка и её сессионный контекст сохраняются при переходах в другие категории и обратно. Кэш не подменяет сверку с реальным содержимым.
- После закрытия Катрана текущая папка сбрасывается; её можно снова найти в истории. Избранное и история не равны восстановлению открытой сессии.

<callout icon="⚠️" color="orange_bg">
<b>Folder — настоящая файловая система, не только карточки.</b> Удаление файла отсюда удаляет его в оригинальной папке. Downloads и Screenshots — такие же управляемые папки с отдельным интерфейсом, а не коллекции без права менять оригиналы. Текущий путь и смысл файловых операций должны быть различимы в интерфейсе. Удаление — через корзину Windows; безвозвратное удаление не является новой функцией патча.
</callout>

## 🔎 Поиск папки, история и избранное

Ctrl+Shift+K открывает поиск поверх Катрана. За основу берётся готовый подход Everything из Afio; переносимость конкретного кода и зависимостей проверяет разработчик. Результат выбора — открыть конкретную папку в Folder, а не импортировать всё её дерево в хранилище Катрана.

| Команда внутри поиска | Поведение |
| --- | --- |
| Ctrl+Shift+K | Обычный поиск папок через Everything; возвращение сюда из истории или избранного |
| Ctrl+H | История папок/переходов; ввод фильтрует записи истории, стрелки перемещают выбор |
| Ctrl+F | Избранные папки; ввод фильтрует избранное, стрелки перемещают выбор |

Ctrl+. в Folder добавляет или убирает текущую папку из избранного. Здесь это не pin отдельного файла. Поиск, история и избранное — режимы одной панели, а не дополнительные постоянные табы потоков.

История позволяет вернуться к ранее открывавшейся папке. В настройках есть отдельная очистка истории Folder с подтверждением «Действительно удалить историю?». Это не удаляет файлы, сами папки или избранное.

## 📦 Копирование в рабочую папку

Основной путь: выбрать один или несколько объектов в номерной категории → Ctrl+C → Tab → Ctrl+V. Результат появляется в текущей Folder. Исходники при копировании сохраняются.

| Объекты из потоков | Результат вставки в Folder |
| --- | --- |
| Существующие файлы и изображения | Копии файлов в папке назначения |
| Изображение, сохранённое Катраном из Clipboard | Файл изображения из собственного объекта |
| Текстовые фрагменты | Отдельные TXT или MD по доступному представлению; расширение MD не обещает восстановления потерянной разметки |
| Таблицы | Отдельные CSV с сохранением структуры, пустых значений и Unicode |
| Выбранные ссылки | Один bookmarks.html с выбранными адресами, пригодный для штатного импорта закладок в браузер |
| Смешанная выборка | Соответствующие файлы по типам; выбранные ссылки собираются в общий bookmarks.html |

Обычный Ctrl+C для нескольких ссылок по-прежнему отдаёт наружу текстовый список URL. Превращение в bookmarks.html — специальное поведение вставки собственной выборки Катрана в Folder, а не глобальная замена Clipboard-формата. Импорт этого HTML в браузер выполняется штатными средствами браузера, без изменения его профиля Катраном.

В Folder лежат уже настоящие файлы. Одиночные и множественные Ctrl+C и drag-and-drop передают именно эти файлы в совместимое окно. Повторного смыслового разбора CSV, TXT или bookmarks.html и специальных преобразований по исходному типу объекта здесь нет.

При совпадении имён операция не должна молча перезаписывать существующие файлы; конкретное разрешение конфликтов и поведение при частичных ошибках проверяются в реализации.

## ✂️ Ctrl+X — перемещение с защитой pinned

Ctrl+X → Tab → Ctrl+V переносит выбранный материал в Folder. Источник удаляется только после успешного создания и проверки соответствующего результата в папке назначения. Нажатие Ctrl+X само по себе ничего не удаляет. При ошибке или неполном результате непереданные исходники сохраняются.

| Источник | Что происходит после успешной вставки |
| --- | --- |
| Незакреплённый собственный объект Катрана | Уходит из Катрана; собственный исходный файл удаляется после успешной передачи |
| Незакреплённый файл Downloads или Screenshots | Настоящий оригинал перемещается в целевую Folder, а не остаётся в исходной папке |
| Pinned-объект любой категории | В Folder создаётся копия; исходник и закреплённая запись остаются на месте |
| Смешанное выделение | Незакреплённые перемещаются, закреплённые копируются; результат операции сообщает о сохранённых pinned |

<b>Уточнение Лилии:</b> Downloads и Screenshots находятся под файловым управлением Катрана. Исключения «убрать только карточку, оставить внешний оригинал» для Ctrl+X здесь нет. Pin — принципиальная защита от удаления средствами Катрана, поэтому действует и на удаляющую часть перемещения.

Для ссылок, текста и таблиц перемещение завершается только после успешной материализации результата. Сам факт помещения текста в системный Clipboard не является подтверждением передачи файла.

## ↩️ Возврат из Folder в Катран

<callout icon="🔁" color="blue_bg">
<b>Передать файл из Folder — не значит заново принять его в Катран.</b> Иначе материал, который только что убрали из потока через Ctrl+X, сразу возвращался бы при обычном копировании наружу.
</callout>

- Ctrl+C и drag-and-drop из Folder работают как обычная передача файлов. Собственное копирование Катрана не создаёт повторный захват в его потоках.
- Для намеренного возврата выбрать нужные файлы в Folder и нажать Ctrl+Shift+C.
- В палитре команда называется «Добавить в Катран»; сочетание должно быть видно, поскольку его смысл не очевиден из Ctrl+C.
- Команда принимает выбранные файлы обратно в применимые категории Катрана. Это явный приём, а не изменение обычного копирования из папки.
- По существующему файлу нельзя обещать восстановление прежней сущности ссылки, таблицы или всех старых метаданных после её удаления: конкретная классификация импорта должна быть проверена отдельно.

## 📌 Pinned в каждой номерной категории

Закреплённые объекты остаются видимыми в обычном потоке своей категории. У каждой категории собственный pinned-срез: картинки с картинками, текст с текстом, ссылки со ссылками и так далее. Общего смешанного pinned-хранилища нет.

Ctrl+. закрепляет или снимает закрепление с одного или нескольких выбранных объектов. Для смешанного выбора: если есть незакреплённые, закрепить всю выборку; если закреплены все, снять pin со всех.

- Обычное удаление смешанной выборки пропускает pinned, удаляя только незакреплённые.
- Отдельной команды удаления pinned, обхода защиты или «удалить всё, включая pinned» нет. Сначала нужно снять pin.
- Ctrl+X не обходит защиту: pinned копируются, а не удаляются из источника.
- Pin защищает от операций Катрана, но не восстанавливает файл, который удалили или переместили другим способом. Актуальность внешнего источника проверяется по реальному состоянию.
- Folder не поддерживает pinned-файлы. Ctrl+. там относится к избранному для текущей папки.

### Повторная цифра без таймера

Цифра другой категории сразу открывает её обычный поток. Повторное нажатие цифры уже открытой категории ведёт в её pinned; следующее возвращает обычный поток. Пример: Images находится на 1 → 1 открывает Images → ещё 1 открывает pinned Images.

После ухода в другую категорию возвращение всегда открывает обычный поток, независимо от прежнего pinned-состояния. Не нужно помнить, какие категории оставлены в pinned.

Специального окна двойного нажатия и ожидания перед первым переходом нет: переключение определяется текущим состоянием. Быстро пришедшее второе нажатие может отменить ненужную загрузку обычного потока или сделать её результат неактуальным; это оптимизация реализации, а не задержка интерфейса.

### Имя и приложение открытия

Ctrl+E для pinned открывает панель свойств объекта. Можно задать понятное имя и приложение, которым этот объект открывается по умолчанию. Это относится к разным типам pinned, а не только к ссылкам.

Панель редактирует оболочку объекта в Катране, не превращаясь в редактор текста, таблиц или содержимого изображения. Имя объекта не должно неявно менять URL или переименовывать внешний оригинал.

## 🏷️ Теги только для pinned

Теги доступны pinned-объектам всех существующих номерных категорий. Pinned и их фильтрация не смешиваются между категориями. Пример использования для ссылок — пользовательский тег Notion; это не обещание автоматически определить происхождение любой ссылки.

- Ctrl+T открывает панель тегов текущей категории в pinned-пространстве.
- Стрелки перемещают выбор; выбор тега показывает только закреплённые объекты с этим тегом.
- Одновременно активен один тег. Множественного выбора тегов-фильтров нет.
- Выбор другого тега заменяет фильтр. Повторный выбор того же тега снимает фильтр и показывает все pinned текущего пространства.
- Нажатие цифры текущей категории сбрасывает режим тегов и возвращает все элементы обычного потока этой категории.
- Переход в другую категорию также завершает режим; при возвращении открывается обычный поток.
- У незакреплённых объектов и у файлов Folder тегирования в рамках этого патча нет.

Один активный тег-фильтр не означает ограничение «один тег у объекта». Способ назначения тегов и их поведение после снятия pin уточняются при реализации, не расширяя фильтрацию на незакреплённые объекты.

## 🕒 Дата собственных объектов · P4

Проблема касается прежде всего скопированных из браузера изображений и других создаваемых Катраном материалов: у них должна быть осмысленная дата изменения, соответствующая моменту добавления в Катран.

При создании собственного объекта/файла инициализировать дату изменения временем поступления: для скопированной картинки-дубликата, текста, ссылки и таблицы/CSV. Сохранять это исходное время при поздней материализации экспорта, чтобы случайное время подготовки временного файла не заменяло дату объекта.

Downloads, Screenshots и другие внешние файлы уже имеют даты от создавших их программ. Их существующие даты не переписываются в дату захвата Катраном. Речь об осмысленном времени собственных объектов, а не о замене настоящей даты внешних файлов или массовой перезаписи EXIF.

Исходный приоритет — незначительный P4. Привязку времени каталога и файловой даты проверяет разработчик.

## 😀 Эмодзи Raycast в текстовом потоке

## ✅ Приёмка Лилией

### Рабочая папка

- [ ] Через Ctrl+Shift+K найти папку и открыть в Folder: видны только её файлы, без вложенных папок и дерева.
- [ ] Проверить локальный поиск, множественный выбор, сортировку, Space, палитру, открытие в приложении и показ в Проводнике.
- [ ] Добавить и удалить файл внешним приложением: Folder отражает изменение без перезапуска и не выдаёт устаревший кэш за реальность.
- [ ] Перейти в номерную категорию и обратно: папка сохранена. Перезапустить Катран: открытая папка сброшена, история позволяет вернуться.
- [ ] Ctrl+. меняет избранное текущей папки; Ctrl+F и Ctrl+H в панели позволяют фильтровать и выбирать; Ctrl+Shift+K возвращает обычный поиск.
- [ ] Очистка истории требует подтверждения и не удаляет файлы или избранное.

### Передача и перемещение

- [ ] Ctrl+C → Tab → Ctrl+V работает для одного/многих файлов, изображений, текстов, таблиц, ссылок и смешанной группы; исходники сохраняются.
- [ ] Несколько ссылок вставляются одним bookmarks.html; проверить штатный импорт в браузеры Chrome, Firefox и Edge, адреса, имена, Unicode и порядок. Снаружи Ctrl+C ссылок по-прежнему возвращает текст.
- [ ] Ctrl+X → Tab → Ctrl+V убирает переданные собственные объекты из Катрана и перемещает настоящие оригиналы из Downloads/Screenshots.
- [ ] В смешанной группе pinned сохраняются в источнике и дают копии в назначении; непереданные при ошибке объекты не удаляются.
- [ ] Проверить одинаковую папку источника/назначения, конфликты имён, недоступный путь и частичную ошибку без потери исходников и молчаливой перезаписи.
- [ ] Обычные Ctrl+C и drag-and-drop из Folder передают один/много файлов наружу и не возвращают их в потоки Катрана. Ctrl+Shift+C намеренно добавляет выбранное обратно.
- [ ] Удаление в управляемой папке действует на настоящий файл; pinned защищены при удалении средствами Катрана.

### Закреплённые объекты

- [ ] Проверить отдельные pinned-пространства всех категорий, отображение pinned в обычном потоке и массовое pin/unpin.
- [ ] Повтор цифры переключает срез сразу; возврат из другой категории открывает обычный поток; быстрые нажатия не подменяются завершившейся фоновой загрузкой.
- [ ] Массовое удаление пропускает pinned; снять pin и удалить можно, отдельного обхода защиты нет.
- [ ] Ctrl+E сохраняет имя и приложение открытия; оболочка не меняет сам URL или внешний файл. Закрепления и свойства переживают перезапуск.
- [ ] Теги работают у pinned разных типов, фильтруется одна категория и один тег за раз; проверить все способы выхода и отсутствие тегирования незакреплённых.
- [ ] Внешнее удаление закреплённого файла не маскируется обещанием его сохранности.

### Даты, шум и регрессии

- [ ] Собственные изображения/текст/ссылки/таблицы имеют исходное время добавления как начальную дату изменения; поздний экспорт не теряет это время. Даты внешних файлов сохранены.
- [ ] Реальная вставка эмодзи Raycast не засоряет текстовый поток после согласованного решения; намеренное копирование проверено отдельно.
- [ ] Основные сценарии принятой 2.0 — сбор, просмотр, порядок выборки и групповая передача — не сломаны. Старый All заменён намеренно.
