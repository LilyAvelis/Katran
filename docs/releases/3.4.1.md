# Katran 3.4.1

First published 3.4 release. Adds English and Russian interface languages; new profiles start in English with the Blue Experimental theme and Lily background 1. Existing profiles keep their saved language and appearance. See [3.4.0 notes](3.4.0.md) for the full change.

The v3.4.0 workflow stopped at an outdated test expectation before building or publishing release assets. This patch corrects that test; application behavior is unchanged apart from the version number.
