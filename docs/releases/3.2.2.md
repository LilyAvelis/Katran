# Katran 3.2.2

Quality-of-life update to 3.2.0:

- Each shelf tab, including Folder and hidden tabs, remembers its own sort,
  gallery or stream view, and density across restarts.
- Window appearance and disappearance can use scaling, fading, or both, with
  independent styles and durations. The existing slide animation remains the
  default. Fade on a glass viewport still needs owner visual feedback.
- The scrollbar keeps card geometry stable when filtering to a small pinned
  set. Its edge spacing accounts for the panel's existing inset.

The 3.2.0 feature set and its limitations remain documented in
[3.2.0](3.2.0.md). Windows visual checks are performed by the owner.
