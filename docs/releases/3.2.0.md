# Katran 3.2.0 · local milestone

Accepted by Lilia for the installed Windows build on 2026-11-12. This source
milestone is pushed to GitHub main. It does not create a release tag, portable
archive, setup package or in-app update. The latest public distribution remains
3.1.1 until a separate release run.

## What changed

- **Files** is visible by default and stores pointers to arbitrary regular
  files. Deleting a Files card removes its pointer, not its original. `Ctrl+Tab`
  copies a selected file to Folder and keeps the pointer; `Shift+Tab` moves it
  and removes the pointer after success. Pinned sources remain protected. Batch
  failures are reported per item.
- **Pinned and tags:** `.` filters the current shelf to pinned items;
  `Ctrl+.` changes pin state. Pinned items can hold one of nine named tag slots.
  `/` opens the tag menu, a digit filters, `Shift+digit` assigns, `/` again
  clears only the tag filter, and `Ctrl+0` removes assignments. Assigning the
  same slot again toggles it off; assigning another replaces it. Unpinning
  removes the assignment but leaves the tag definition.
- **Tag materials** have color, opacity and procedural textures. Their
  material fills the card background across Links, Text, Images, Pods and other
  shelf types. The single pin marker takes the tag color when assigned.
- **Custom pin order:** `, Y` puts pinned cards first in the user's saved
  order, followed by other cards in arrival order. Actions has Move Up/Down
  for pinned items, with `Ctrl+Alt+↑/↓` shortcuts. A move crosses one visible
  pinned card in the current tab; hidden categories do not steal a step.
  Other sorting modes keep their existing order. Folder has no pins.
- **Navigation and selection:** `Ctrl+A` selects the current shelf or Folder
  space, including additional pages; the two spaces do not mix. Search can be
  toggled with `Ctrl+T` and can optionally require that shortcut. Settings is
  a separate, nonblocking window, so the main shelf remains usable while it is
  open.
- **Visual polish:** optional separate glass tab buttons, improved tab motion,
  compact site icons for Links, optional online favicons with manual refresh,
  centered Text/Links previews and a fixed right-side scrollbar lane. Theme
  settings can make the scrollbar glass, always visible when needed or only
  visible while scrolling. Optional wheel inertia has speed and duration
  controls and is off by default.
- Clipboard Text/Links deduplication now follows the existing Pods approach,
  including objects copied out of Katran. Shared glass-tab and tag-material
  mechanisms were added to the reusable Avilon design workspace.

## Controls and limits

Tagging requires pinning first. Files remains a pointer shelf, not a file tree.
Online favicon retrieval is opt-in; refreshing stored links is a visible manual
action. Smooth scrolling changes only Katran, not Windows globally. The settings
window has functional grouping but still awaits a dedicated visual polish pass.

The 3.2.0 package version names the installed local build. Windows visual checks
are performed by the owner; automated checks use synthetic data and the domain
API. The current implementation and command contracts are in the source tree.
