# Katran 3.8.0 · local candidate

This is preparation and implementation, not a published release. The installed
working application is not replaced. The accepted scope is documented in
[PRODUCT.md](../patch-3.8/PRODUCT.md); implementation state and verification
belong to [TEAM.md](../patch-3.8/TEAM.md).

- Independent tag sets per shelf tab, preserving previous definitions, material
  settings and object assignments during migration.
- Inline accordion tag editing with live persisted styling.
- Algorithmic Everything folder ranking, contextual Folder favorites/history
  and visible access to six OS-resolved Windows Known Folders.

Folder AI search is deferred. Ctrl+Shift+Comma retains contextual behavior;
Ctrl+Y is a proposal rather than a newly assigned shortcut. Native Windows
acceptance and real Everything before/after results remain separate evidence.

The candidate upgrades a profile to schema v13 after a consistent backup.
Rollback to 3.7.1 requires that backup; switching only the executable is not
sufficient. The staged preview uses a separate profile. Automatic migration of
the owner's active profile has not been performed.
