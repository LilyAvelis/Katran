# Katran 3.8.0 · local candidate

Folder neural embeddings now persist across Katran/worker restarts. Compatible
vectors are reused and only new/renamed/moved descriptors are encoded; removed
entries are pruned from the bounded cache. Model/preprocessing changes invalidate
incompatible data. CPU/GPU caches are separate; no catalogue migration is needed.

Native-feedback refinement: Mini stream Text rows use the first nonempty content
line, with explicit display names taking priority. Every pinned row now shows
the usual orange/tag-colored dot. Text supports Ctrl+Left/Right to choose
Markdown/source directly in the split view, preserving cursor and selection.

Neural Folder queries now submit only on Enter and initially show 10 results;
Down at the last row requests another snapshot-bound page of 10. Settings adds
an opt-in GPU indexing checkbox using an isolated optional CUDA environment;
missing CUDA is explicit and leaves ordinary search available.

Later owner follow-up implements the previously researched **Mini stream**:
Actions → Display and Settings → General → Appearance → Tab view both offer it.
It presents compact rows at left and cursor preview/metadata at right, using
the standard selection and domain actions across providers. The mode is saved
per tab; older binaries require settings-aware rollback for `view: details`.

Folder's configured Standard shortcut now works inside the open picker while
its search field is focused. In the Search section, physical backslash toggles
an optional local neural mode, consuming the corresponding character and showing
a gold field border. It uses the already installed model and a bounded index
of folder names/paths; incomplete coverage and runtime errors remain explicit.
No automatic download, content indexing or cloud requests were added. See
[Mini stream](../patch-3.8/DETAILS-VIEW.md) and
[Folder neural mode](../patch-3.8/FOLDER-NEURAL.md) for scope and limitations.
