# Katran 3.8.0

Katran 3.8 adds independent tab tags, a compact split view, local neural Folder
search and direct global shortcuts to each tab, with refinements driven by daily
use. Optional AI components install separately; model weights are not bundled.

## Tags that follow your workspace

- Each tab has its own tag names, colors and textures. Existing assignments are
  preserved by the schema-v13 migration.
- Drag complete tags in Settings to change their order and number shortcuts.
- In the tag palette opened by `/`, Ctrl+Shift+, opens a compact live editor
  without leaving the shelf. Slash/backslash dismiss it; focus loss releases it.
- Comma, then `/` sorts by current tag order, with untagged items last. Custom
  pinned order remains a separate mode. Folder has no tag slots.
- Rename, pin, tag assignment and live styling retain unchanged image previews.

## Mini stream

Actions → Display and Settings → General → Appearance → Tab view offer a third
view: a dense list at left, selected-item preview and available metadata at right.
It uses the same selection, copy, drag, pin, tags and actions as the other views.
Text rows use their first nonempty line, unless explicitly renamed; pinned items
show the usual dot. Ctrl+Left/Right switches Text Markdown/source in this view.
View choice is saved separately for each tab.

## Folder and local AI

- Improved Everything-backed ordinary search, with name-aware ranking and
  reduced technical noise. Ctrl+Y opens standard Windows folders; Ctrl+F/H open
  favorites/history, including switching inside the picker. Shortcuts can change.
- Backslash in Folder search toggles optional local neural search; queries run
  on Enter, with ten results and another page when pressing Down at the last row.
- Optional CUDA acceleration for Folder. Compatible embeddings persist between
  restarts; new/changed descriptors update incrementally.
- Settings → AI installs and verifies Emoji, Folder and optional CUDA components
  in a visible terminal with a saved journal. CPU use remains available.
- [Install AI on another PC](https://github.com/LilyAvelis/Katran/blob/v3.8.0/docs/ai-setup.md).
  Fresh-machine setup still needs practical validation; no universal GPU claim.

## Keyboard and paste

Settings → Tabs can register a Windows-global shortcut opening a particular tab
with its saved view. Ctrl/Alt/Shift and punctuation recording support is improved.
Enter follows the last external window when returning to Katran; stale paste
intents cancel on focus changes. File Clipboard receipts are verified after
publication teardown. The owner confirmed the formerly failing Notion browser
file-paste scenario now works. Pinned properties have a refined form and Ctrl+Enter.

## Install and compatibility

Download the Windows x64 setup or extract the portable ZIP into a new directory
and run Katran.exe. Close Katran before setup; existing users can use Settings →
Updates after publication. Model/runtime downloads are optional, separate from
the application and its update ZIP. Binaries remain unsigned.

Back up the profile before upgrading. Data schema is v13. Older versions cannot
open that profile safely; saved Mini stream/Tags sort settings also require a
settings-aware rollback. Retain the prior executable and compatible backup.

Local native checks accepted the new tag sorting and image retention. Automated
API/UI evidence and remaining limitations are recorded in docs/patch-3.8;
release CI independently checks, builds, packages and publishes immutable assets.
