# Katran 3.4.0

Katran now offers English and Russian interface languages in Settings → General → Interface language. New profiles start in English with the Blue Experimental theme and Lily background 1. Existing profiles keep their saved appearance and Russian language until changed in Settings.

Actions, settings, shelf controls, previews and the Windows tray follow the selected language. Object names, custom tag names, URLs and file content remain as entered by the user. A language change takes effect after saving, without restarting Katran.

Includes all [3.3.1 changes](3.3.1.md). Existing data remains compatible.
