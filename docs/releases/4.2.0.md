# Katran 4.2.0 · Pages

**Pages** is a flat Obsidian vault for notes you choose to keep nearby. In
**Text**, select one or more snippets or text BULLs and use **Ctrl+K → Move to
Pages**. Clipboard captures continue to land in Text. You can also create or
edit Markdown files directly in the Pages vault from Obsidian. On first
use, open the `Katran Pages` folder inside your Katran data directory as a
vault in Obsidian.

- In **Pages**, **Alt+Enter** opens a Markdown note in Obsidian. **Space**
  reads it in Katran, including Markdown images and Obsidian embeds that
  resolve to local media. Raster previews appear inline and other supported
  media can open in the system viewer.
- Pack Markdown notes into a BULL and unpack them back into Markdown from
  Actions. Attachments remain as files in the vault.
- **Text** still opens its Obsidian draft with **Alt+Enter** and picks up
  saved edits when you open its preview with **Space**. Text, Pages, and
  text BULLs share Katran's Markdown reader, including Notion callouts,
  tables, and toggles.
- Settings → Tabs supports up to nine numbered tabs. Folder remains on
  **0**. Disable a numbered tab to make room when all nine slots are used.

## If you are coming from 3.8

This release also includes the [4.0 collection and media tools](https://github.com/LilyAvelis/Katran/blob/v4.0.0/docs/releases/4.0.0.md)
and the [Atelier settings and Notion integration](https://github.com/LilyAvelis/Katran/blob/v4.2.0/docs/releases/4.1.5.md).
You get portable BULL and BS archives, image translation and upscaling,
Notion browsing, and a redesigned Settings interface with font controls,
reorderable sections, and optional glass navigation.

On Windows x64, use **Settings → Updates** or close Katran and run
`Katran-4.2.0-windows-x64-setup.exe`. Back up your profile before updating.
Katran also keeps a pre-migration catalogue backup for rollback. The
portable ZIP is available alongside Setup. Windows binaries are unsigned.
