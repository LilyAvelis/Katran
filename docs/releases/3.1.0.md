# Katran 3.1.0

## Appearance and video backgrounds

- New profiles start with the Blue theme and the first lily preset. Existing settings are preserved; Standard remains available.
- Five lily presets, managed custom images, optional Acrylic and GPU refraction can be combined. Selection has its own color and optical intensity.
- Silent video backgrounds can be imported from Themes or a selected Downloads video. The original is unchanged; Katran keeps a managed copy.
- Short clips use a bounded frame cache, optional seam blending and hardware-assisted decoding. Hidden windows stop playback and release the frame cache. Long clips use streaming; this is not zero-copy decoding.
- Apple color emoji are included as a private compact font resource. General settings can select Windows emoji or an imported font. Clipboard text stays Unicode; the receiving app chooses its own rendering.

## Workflow improvements

- Ctrl+K commands, a dedicated comma sorting menu with arrow navigation, configurable sorting hints and centered preview help in the footer.
- Enter pastes into the previously active application; Alt+Enter opens in the default application. Actual image/file acceptance depends on the target application.
- Ctrl+Tab copies and Shift+Tab moves between a shelf and Folder, including repeated transfers and explicit per-item failures.
- Folder search accepts full paths; Explorer integration opens the selected directory through the same domain command and records history.
- Restart is available through Ctrl+K. Global show/hide and tray operation keep the current profile.
- ShareX screen recordings appear in Screenshots and open through Quick Look.

## Installation and resources

Download the portable ZIP or per-user setup from GitHub Releases. Extract the entire portable archive and run Katran.exe. Binaries are unsigned.

The portable and setup packages include pinned FFmpeg components. The legacy in-app update remains a three-file archive compatible with 3.0. After such an update, missing video components can be installed explicitly from Themes (~73MiB). The optional media-runtime asset is checksum verified before bounded extraction.

No personal video, profile settings, clipboard history or exports are distributed. Fresh installs contain no video background; choose your own file. The five lily presets and Apple emoji resource are included. Large emoji previews scale the bundled 96px strike.

The Apple font conversion source is samuelngs/apple-emoji-ttf, macos-26-20260722-484daf4e. Apple's artwork remains Apple's asset; the converter code license does not grant artwork rights. FFmpeg provenance and upstream license accompany its runtime. See the repository contracts for technical details.
