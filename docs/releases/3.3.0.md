# Katran 3.3.0

## Actions

- Actions are organized into contiguous groups for the selected object, Folder transfers, navigation, display, pinned order, appearance and the application.
- Search matches action names, groups and related terms. Sorting stays in its dedicated menu and can also be found by searching Actions.
- Labels for Folder transfers, tab navigation and the pinned filter describe their current effect. Actions keep their existing IDs and keyboard shortcuts.

## Daily use

- Visible shelves preload their first page in the background, reducing the pause on the first tab change.
- The optional video background setting keeps playback running while the main window is hidden, avoiding a restart on reopening at the cost of continued resource use.
- Settings can be closed with Ctrl+, from the main window or by clicking the Settings heading.
- Favorite folders can be removed from the Everything picker even after their source path disappears; the action gives feedback.

Existing Katran data remains compatible. See [3.2.3 notes](3.2.3.md) for the preceding release.
