# Katran 3.7.0

Katran 3.7 adds an emoji catalogue inside Pods and gives the application a new icon.

- Browse emoji by category, select several at once, copy them into saved Pods, or paste one directly into the previous window. Saved Pods still contains only the items you choose to keep.
- Keep image and video backgrounds in Desktop. Images saved in Katran can now be used as the Katran background or as Windows desktop wallpaper. Video actions can hand a copy to Wallpaper Engine, including a silent copy.
- See a clear busy state during larger transfers and physical deletions. Smaller operations keep the usual uninterrupted interface.
- Internal command, storage, selection and background handling have been strengthened so the same actions work consistently across shelves. This release also includes recovery and integrity improvements for managed files.

Existing data and settings remain in the same profile. The data format advances to version 12; older Katran builds cannot open the upgraded profile without restoring its pre-upgrade database backup.

Windows x64: choose the per-user setup or extract the portable ZIP into a new directory. The in-app updater replaces the application executable; a full setup or fresh portable extraction also updates the launcher and its Windows icon.
