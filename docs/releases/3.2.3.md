# Katran 3.2.3

This release contains the 3.2.2 quality-of-life changes: per-tab view, sort
and density preferences, additional window animations, and stable scrollbar
spacing. See [3.2.2 notes](3.2.2.md) for details.

The 3.2.2 tag did not produce a release because older tests still expected the
previous shared Links density and catalogue schema version. Those test
expectations are corrected here; application behavior is unchanged from the
locally accepted preview.
