# Katran 4.1.5 · Atelier

Atelier brings the 4.1 Notion integration and a redesigned Settings interface
to the public Windows build.

## If you are updating from 3.8

Atelier is intended as a direct upgrade from 3.8. Back up your Katran data
before updating so you can restore it if you need to go back to 3.8.

- **Collections.** Use **Ctrl+K → Pack / unpack collection** to group images,
  links, text, or compatible files into a BULL. Mixed files form a BS. Open a
  collection with **Space** and press **Ctrl+C** to copy the current entry.
- **Image tools.** Translate images from Japanese, Simplified Chinese,
  Traditional Chinese, or Korean into English. Upscale images with Remacri or
  Real-ESRGAN at ×2 or ×4. Both tools accept image BULLs and preserve page order.
- **Media.** Extract a video's audio as M4A, or send a selected image to Google
  Lens from Actions.

[Full 4.0.0 changes](https://github.com/LilyAvelis/Katran/blob/v4.0.0/docs/releases/4.0.0.md)

## Settings and the shelf

- In **Settings → Aesthetic**, choose an interface font and see it apply
  immediately. Drag sections into your preferred order and opt into centered
  headers, raised panels, or glass navigation.
- Press **Ctrl+Shift+↑/↓** to move between Settings sections and **Ctrl+T**
  to toggle focus in Settings search.
- Record shortcuts in the shared editor in General, Shortcuts, Tabs, and
  Actions. Choose raised keycaps independently for the editor and Settings rows.
- Edit tags in Settings or from the shelf. The Settings editor shows a
  full-card preview. The shelf editor sits near the footer so you can see the
  cards change as you adjust their tags. New materials include Flowers,
  Stars, Diamonds, and Grid.
- Experimental glass navigation uses the current image or video background
  for refraction when GPU optics is available.

## Notion and search

- **Ctrl+Shift+N** opens the Notion picker. Search page titles, browse
  databases, read Markdown in Katran, or attach a page as a Markdown file.
  Katran uses a read-only Notion connection.
- Folder and Notion search have clearer keyboard hints. Neural Folder search
  has a glow around its input, and Folder results display ordinary Windows paths.
- [Notion setup and shortcuts](https://github.com/LilyAvelis/Katran/blob/v4.1.5/docs/notion.md)

## AI setup

- **Settings → AI** includes **Install** and **Verify** for image translation
  and upscaling. The same installer fixes Windows PowerShell 5.1 startup for
  Emoji and Folder search. Verify runs a small functional check and reports
  the result in a log.
- Optional models download separately. Image translation requires a GPU with
  enough memory for Qwen. A full AI setup test on a separate clean Windows
  computer remains pending.
- [AI setup guide](https://github.com/LilyAvelis/Katran/blob/v4.1.5/docs/ai-setup.md)

## Updating on Windows x64

Use **Settings → Updates** in an existing installation, or download
`Katran-4.1.5-windows-x64-setup.exe`. Close Katran before running Setup.
For a portable copy, extract the portable ZIP and run `Katran.exe`.
The Windows binaries are unsigned.

The new tag materials use catalogue schema 16. Keep the pre-upgrade backup if
you need to return to a build that uses schema 15. The update ZIP is intended
for the in-app updater.
