# Katran 3.0 · public package 3.0.1

Owner-accepted on 2026-11-11. This release combines the local 2.5 development
cycle with the optional Blue redesign; there is no separate public 2.5 release.

## Everyday workflow

- Folder replaces All: select a working folder through the Everything folder
  picker, then use Tab to switch between it and a category.
- Shift+Tab moves selected objects in either direction; Ctrl+Tab copies and can
  be repeated. Name collisions create numbered copies. Pinned objects remain
  protected; batch results report failures individually. Folder imports create
  managed images, so a round trip does not block later transfers.
- Pods collects emoji/symbol sequences with deduplication, compact tiles, pins,
  color rendering and Unicode details on Space. Copy concatenates selections;
  drag exports one text file.
- Pinned objects have category-specific views, names, tags and application
  preferences. Ctrl+Shift+Left/Right navigates categories and exits pinned mode.
- Katran lives in the system tray. Record a global shortcut in Settings to
  toggle the overlay over the current app. Enter pastes into that captured app;
  Alt+Enter opens the selected item in its default app.
- Comma opens a dedicated Sort palette. Use arrows and Enter or its displayed
  letter shortcuts; Shift selects reverse order. Optional two-second sort hints
  can be disabled in Settings. Ctrl+K retains the other actions.

## Optional appearance

Standard remains available. Blue adds semantic colors/accent, five lily
background presets and optional Windows Acrylic glass. Glass can coexist with
artwork and translucent card surfaces. Import custom backgrounds into managed
storage or use an image's **Use as background** action. Presets stay intact.
Settings offers restart confirmation when the window effect requires it.
Compact borderless windows and a shared bottom status strip remove excess
chrome; Ctrl+Comma toggles Settings.

## Reliability and boundaries

Review fixes cover clipboard cut receipts, exact URL Open With, native clipboard
publication ordering, recovery visibility, asynchronous image preparation and
revision checks, modal input ownership, EXIF orientation, and managed-file alias
protection. Everything ES is embedded for in-app updates and included in full
packages with its notices; the separate Everything application is still required.

Windows clipboard events remain the default. Native paste depends on Windows
focus/security restrictions and the receiving application. Acrylic can fall
back to opaque rendering. Binaries are unsigned. Afio integration and extraction
of reusable libraries are future work, not features of this release.

## Installation and updates

Download from [GitHub Releases](https://github.com/LilyAvelis/Katran/releases/tag/v3.0.1).
Existing installations: **Settings → Updates → Check**, install, then restart
Katran. Updates are manually checked; publication does not send a push message.
The three-file update format and launcher protocol remain compatible with 2.0.
Use the full setup or portable package to replace the CLI/launcher too. Existing
profile data is retained; do not replace it with development fixture data.
