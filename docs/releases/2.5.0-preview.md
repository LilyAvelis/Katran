# Katran 2.5.0 local preview

**Status: in development; not accepted and not published.** The accepted public
release remains 2.0.0. This page records a local preview checkpoint and its
known limits; it is not a release announcement.

## Implemented

- Folder replaces All with live folder search, history/favorites, navigation,
  previews, and a bundled Everything backend.
- Pinning, category-local properties/tags, history and favorites use additive
  SQLite schema 8 with backups.
- Verified copy/materialization, staged cut, explicit return import, and
  negative-snapshot preview API are connected to the UI.
- Managed Downloads and ShareX originals, including Screenshots, use verified
  staging and Windows recycle. External files pasted into Folder are copied;
  external clipboard cut is not implemented.
- New Katran-owned objects preserve ingest time as their modified time on late
  export. External timestamps are unchanged.

## Known limits

- Folder negative-ID cut is explicitly unavailable; same-folder transfer is a no-op. Folder
  delete is supported only through verified staging/recycle. Recovery can
  require manual paths.
- Explicit import currently handles fresh TXT/MD, CSV, images and bookmarks HTML
  as per-URL links. Other formats return errors. Source references are not
  typed, and old metadata is not restored.
- External clipboard paste copies; external clipboard move/cut is unsupported.
- Properties/tags GUI is implemented. The opener is an opaque handler ID; native
  browser URL opening is uncertain.
- Raycast filtering is not implemented because no reliable clipboard marker
  has been established. Intentional emoji remain allowed.
