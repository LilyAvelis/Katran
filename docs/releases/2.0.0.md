# Katran 2.0.0

Owner accepted the Windows feature flows on 2026-11-10.

- Functional tab visibility: hidden categories stop collection and close their
  numbered navigation positions while retaining saved data.
- Text capture, ordered multi-copy as plain text, individual TXT drag, Markdown
  and exact-source preview.
- Links with plain URL multi-copy and a single combined links.txt drag payload.
- Tables with value-grid capture, HTML + TSV copying between Google Sheets and
  Notion, ordered stacking, CSV drag, internal zoom/pan/fit and CSV source view.
- Table clipboard ownership markers prevent Katran from recapturing its own copy.
- Source/name/natural/extension/size/date/shuffle sorting with comma sequences,
  reverse order, visible criteria and Actions hints.
- Default-app opening, Explorer reveal, and a bottom associated-app picker.
- Portable ZIP and per-user Windows x64 setup; manual update checks in Settings.

The portable archive contains no user database, clipboard history, exports,
logs or credentials. Setup stores user data separately and preserves it on
uninstall. Updates use the official public GitHub release and verify manifest,
archive and executable hashes before switching the immutable build pointer.
Restart Katran manually to use an installed update.

QuickLook remains an optional separate application for other file formats.
Table grids retain values and structure; workbook formulas, styles and arbitrary
nested or partial HTML tables are outside this release's table model. Excel
physical acceptance was not performed; the owner confirmed Google Sheets/Notion.

Binaries and setup are unsigned because no signing certificate is configured;
Windows may show an unknown-publisher warning. Package SHA256 checksums are
published with each release. See [distribution details](../distribution.md)
and [Azuros release review](../reviews/azuros-2.0-release.md).
