# Katran 3.7.1

Katran 3.7.1 brings the recent Pods and Desktop work into one application. Existing Pods, Desktop items and settings remain in the same profile; this patch does not change the data format.

- Desktop Actions and Sorting stay responsive after setting an image or video background. Their menus no longer repeatedly scan the entire background library.
- Press comma again to close Sorting without changing the selected order.
- The emoji collection and its controls are available in the unified app. Additional local components can be installed separately; see [emoji search setup](../emoji-ai.md).

The portable ZIP and per-user setup contain the same application. Existing 3.7.0 release files remain unchanged.
