# Katran 3.7.1 · release candidate

This is a local candidate. Published 3.7.0 files and tag are unchanged.

## One Katran

Katran's public 3.7 codebase is now the only application host. The former E emoji AI search runs through the same Pods catalogue, selection, copy, paste, drag and command dispatcher as the rest of Katran. The local E fork is kept only as historical migration input. There is no separate application identity, account check or payment gate in 3.7.1.

AI search is optional. The model, Python environment and generated index are not bundled with the app. Without them, the AI mode explains how to install the model, and ordinary Katran remains available. The app never downloads the model on its own. A manual installer and instructions are in [Emoji AI setup](../emoji-ai.md). The pinned model is `intfloat/multilingual-e5-small` at revision `614241f622f53c4eeff9890bdc4f31cfecc418b3`.

## Compatibility and scope

The shared profile remains at schema v12; no data migration is added here. The working public native video background path is retained. The optional AI runtime lives under the profile, so executable updates do not carry it or move it. The release packaging includes only the small installation helper, worker source, Unicode/CLDR inputs and license notices; it excludes weights and generated files.

Desktop Actions now checks the selected asset once when building its menu, and Sorting loads only sorting commands. This removes repeated background-library scans that slowed those menus after choosing a Desktop background.

Press comma again to close the Sorting menu without changing the selected order.
