# Katran 4.0.0

Katran can group shelf items and files into portable collections, translate
ordered image batches, and run a local image upscaler.

## BULL and BS

- Use **Pack / unpack collection** in Ctrl+K to collect images, links, text,
  or compatible files into a BULL. Mixed files form a BS. Compatible
  collections can be merged or unpacked. Folder uses the same action and
  verifies the new archive before moving originals to the Windows Recycle Bin.
- BULL and BS hold up to 1,024 entries within a 256 MiB archive. Older
  readers may reject collections with more than 32 entries.
- Open a collection with Space. Page through its ordered contents, zoom
  images, read Markdown, or play video with the optional player. F11 toggles
  fullscreen in BULL. The title and pager hide when you zoom.
- Ctrl+C copies the current image, URL, or source text. Enter pastes it into
  the previous window. Copy or drag the shelf card to transfer the entire
  collection. Ctrl+E renames a collection, including unpinned ones.

## Translate and Upscale

- Translate images from Japanese, Simplified Chinese, Traditional Chinese,
  or Korean into English. Results appear in Translate. A loose image
  produces a PNG, and an ordered selection or BULL produces a new BULL.
  Failed pages in a partially translated BULL remain in place as originals.
- Numbered annotations keep the original lettering and link each translated
  bubble to its numbered card. Cards on each side are ordered by number.
- On one tested complex Japanese page, a warm end-to-end translation fell from
  21.6 seconds to 3.7 seconds during development. The main gain came from
  avoiding repeated text recognition. See the [measurement conditions](https://github.com/LilyAvelis/Katran/blob/v4.0.0/docs/patch-4.0/TRANSLATE.md).
- Remacri and Real-ESRGAN offer exact ×2 and ×4 for static images and image
  BULLs. Each AI command can have its own keyboard shortcut.
- The [AI setup guide](https://github.com/LilyAvelis/Katran/blob/v4.0.0/docs/ai-setup.md) covers the external components required
  for Translate and Upscale. Settings → AI links to these instructions and
  still installs and verifies the Emoji and Folder AI components.

## Media and search

- Extract a selected audio track as M4A. Katran adds it to Files and copies
  it to the clipboard as a file.
- Send one selected image to Google Lens in your default browser.
- For in-app playback, run `scripts/setup-video-player.ps1` from the Katran
  installation or portable directory in PowerShell, then restart Katran.
  Setup and Portable include the helper. If you updated in-app, download
  the [4.0.0 helper](https://github.com/LilyAvelis/Katran/blob/v4.0.0/scripts/setup-video-player.ps1)
  into the installation's `scripts` directory before running it.
- The [external QuickLook image BULL adapter](https://github.com/LilyAvelis/Katran/tree/v4.0.0/integrations/quicklook/QuickLook.Plugin.BullViewer)
  is a separate component for a compatible QuickLook host.

## Updating

Windows x64 Setup and Portable use catalogue schema v15. Keep a backup of
your Katran data before upgrading. Returning to an older version requires
the matching pre-migration backup. Full verification of AI setup on a
second, clean Windows computer remains pending.
