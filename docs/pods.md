# Pods: symbol stream and color rendering

Pods is an optional, initially hidden numbered category. Its eye in Settings controls collection independently of Text. Symbol-only clipboard captures and `IngestText` use the same domain classifier; ordinary text belongs to Text. Copying and transfer use the original full text, not the card preview or rendered pixels.

The classifier in `src/pods.rs` accepts Unicode 16 OtherSymbol, MathSymbol, CurrencySymbol and ModifierSymbol characters, ordinary spaces around/between them, paired regional indicators and valid keycaps; it accepts variation selectors, skin tones and ZWJ combinations only under the checks in that module. It rejects empty/space-only strings, standalone punctuation, ordinary letters or numbers, unmatched regional indicators and malformed joins. This is a bounded classification policy, not a claim to recognize every Unicode emoji sequence. Normalization is not applied: byte-distinct text, including different selectors, remains distinct.

For an exact Pods value the domain reuses an existing text event, preferring an already pinned event, then the newest matching event. It preserves that event's metadata and timestamp rather than creating another arrival. This rule does not merge semantically similar values or modify ordinary Text deduplication. Pinning, tags and selection still use the shared dispatcher.

Windows color rendering uses DirectWrite and Direct2D on an in-memory WIC bitmap, preserving whole native runs; regional flag pairs are rendered from bundled Twemoji SVGs and composed into the image. It does not read the desktop or Clipboard. The worker is lazy, has a 32-item input queue, at most 64 pending keys and a 64-texture cache. While rendering is pending the canvas remains empty; an explicit renderer failure falls back to ordinary text. Rendering accepts 1–128 UTF-16 units at 12–128 pixels and caps each bitmap at 1024×256. Both cards and Space preview use `text_preview`, the first 512 Unicode scalar values: long values may be truncated at a sequence boundary or exceed renderer limits. Full values remain in the domain API and are used for copy/transfer.

Flag graphics are the unmodified regional-flag subset of Twemoji v17.0.2, under CC BY 4.0; see `assets/emoji-flags/ATTRIBUTION.md` and `LICENSE-GRAPHICS`. These notices must accompany distribution. Apple emoji artwork is not bundled. Color depends on the platform font's available glyphs and DirectWrite support; unrecognized or unavailable native glyphs are not promised to be colored. Native Windows appearance remains owner-verified.
