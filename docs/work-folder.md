# Working folder domain projection

`work_folder::State` is session-only. `choose` selects a canonical directory; it does not persist it or import its entries. `browse` enumerates immediate regular files afresh, excludes links/reparse points and subdirectories, filters names case-insensitively, sorts, and returns a page of `Event` values. Cursor fingerprints bind the full observed listing, root, query and sort. An old cursor is rejected after a changed listing or context. IDs are negative, session-local and never reused; choosing a folder invalidates earlier IDs, including when choosing the same folder. `get` checks containment, regular-file status and the metadata revision again.

The metadata revision (path, size, modification time) detects ordinary changes but is not a cryptographic identity or a file-operation authorization. A caller performing deletion, moves or clipboard transfer must independently validate source identity and revision at its own operation boundary; this module never changes files. Enumeration is a live best-effort snapshot, not an atomic filesystem snapshot. A concurrent external mutation can require refresh. This module does not watch the folder, provide persistent history, or implement operations/UI; integration must refresh on source changes. Folder rows have `ShelfOnly` policy until a separate explicit Folder deletion path is implemented, and must never be routed through ordinary shelf deletion.
