## P2 — unrelated Clipboard publication re-arms an old Cut

Evidence: [paste_service.rs:8](https://github.com/LilyAvelis/Katran/blob/81abc6f/src/paste_service.rs#L8), [transfer_service.rs:143](https://github.com/LilyAvelis/Katran/blob/81abc6f/src/transfer_service.rs#L143). record_clipboard_publication binds the existing transfer intent to any new sequence. Ctrl+C restages, but copy_text and Alt+Enter do not. Cut A → select Text B → Actions copy_text (or Alt+Enter B) → Folder Ctrl+V can execute the old move of A. Managed originals can be removed after transfer; cached records can be removed from the shelf.

Minimal fix: bind the publication to its exact staged snapshot/operation; unrelated publication cancels the old cut. Synthetic regression: Cut(A) → CopyText(B) → PasteToFolder must leave A unchanged.

## P2 — Link Open With passes a local TXT instead of the URL

Evidence: [app_picker.rs:191](https://github.com/LilyAvelis/Katran/blob/81abc6f/src/app_picker.rs#L191), [jobs_service.rs:466](https://github.com/LilyAvelis/Katran/blob/81abc6f/src/jobs_service.rs#L466). Sync and job OpenWithApp route to execute_with_cache, producing a backing TXT snapshot even though Link handlers were discovered for .html. Regular Open and pinned-default take a different, correct URL route.

Minimal fix: shared handler dispatch routes Links through execute_link in both paths. Fake Provider test must receive the exact HTTP(S) URL for sync and job requests.

## P2 — text copy receipt can acknowledge another application's Clipboard data

Evidence: [text_fragments.rs:27](https://github.com/LilyAvelis/Katran/blob/81abc6f/src/text_fragments.rs#L27). NativeClipboard calls arboard.set_text, then reads sequence separately. The locked arboard 3.7.0 Windows implementation closes the Clipboard before set_text returns (dependency source inspected). A clipboard manager can replace data before the sequence read, and Alt+Enter accepts that unrelated sequence as its publication receipt.

Minimal fix: publish Unicode text and read sequence under one native guard, matching file/table sinks. Verify publish → sequence → unlock ordering with an injectable backend. This is distinct from the already documented final foreground-check/SendInput race; it was not exercised on the personal Clipboard.

## P2 — completed recycle journals can block all recovery listing

Evidence: [safe_recycle.rs:193](https://github.com/LilyAvelis/Katran/blob/81abc6f/src/safe_recycle.rs#L193), [safe_recycle.rs:366](https://github.com/LilyAvelis/Katran/blob/81abc6f/src/safe_recycle.rs#L366). Successful recycle/restored operations retain their recovery directories and journals. The 1000-directory limit includes completed entries; at 1001 the whole listing errors, hiding even an unresolved recovery.

Minimal fix: paginate unresolved work or safely bound retention of completed journals; never delete unfinished recovery. Synthetic regression: 1000 completed plus one unresolved must leave the unresolved entry available.

## P2 — production packaging omits the Everything helper

Evidence: [package-release.ps1:64](https://github.com/LilyAvelis/Katran/blob/81abc6f/scripts/package-release.ps1#L64), [everything.rs:42](https://github.com/LilyAvelis/Katran/blob/81abc6f/src/everything.rs#L42). Portable/setup/update contain UI executable, notices and manifest; es.exe is required beside current_exe. The local preview separately copies it, so preview acceptance does not validate the production package. Updater currently enforces a three-file contract.

Before 3.0: include helper and licenses in the package/update whitelist and validate the extracted helper resolver through a synthetic updater roundtrip. This needs packaging tests, not a fresh source compilation.
