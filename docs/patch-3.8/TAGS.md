# Теги по вкладкам · 3.8

Вкладки Images, Screenshots, Downloads, Text, Links, Tables, Pods, Files и Desktop имеют независимые девять слотов и независимые назначения. Folder не поддерживает теги. Сохранение оформления меняет только выбранную вкладку; назначение относится к активной вкладке. Удаление закрепления снимает назначения во всех вкладках, как и раньше.

Миграция v12 → v13 выполняется в транзакции после штатного резервного копирования. Каждое определение копируется со всеми параметрами в каждый набор; прежнее назначение объекта копируется во все наборы каталога, а назначение Desktop — в набор Desktop. Это сохраняет прежний вид при первом открытии каждой вкладки, даже если объект доступен в нескольких представлениях. Старые таблицы остаются как исторические данные миграции, не как действующий источник данных. Они не являются резервной копией: каскадное удаление исходного объекта может удалить старую связь. Дальнейшие изменения одного набора не меняют другие. Для возврата к старой версии используется созданная перед миграцией резервная копия; саму базу v13 старые версии открывать не должны.

Проверки используют синтетический профиль с v12, полями оформления и назначением; личный профиль не используется. Сохранение и чтение через API, изоляция наборов, повторное открытие и целостность базы проверяются отдельно от ручной проверки интерфейса.
